# NewWorld Interface Lab

Самостоятельный редактор интерфейсов NewWorld.

**Открыть редактор:** https://wintaris.github.io/newworld-interface-lab/

Страница работает целиком в браузере, без сервера игры. Для локального запуска
скачайте репозиторий и откройте `index.html` в Chrome или Edge.
Python и установка пакетов не нужны. Сохранённые макеты остаются в вашем браузере;
для передачи используйте экспорт JSON.

## Компоновка инвентаря в стенде

В инвентаре показан макет для согласования по референсу: портрет и характеристики
слева, список предметов в центре, оружие и броня справа. Количество и износ
расположены над картинкой слева и справа. Картинки списка увеличены примерно
в полтора раза; между ячейками сохраняется зазор 8 px.
Патроны и износ во всех слотах используют один размер игрового шрифта — 20 px.
Этот макет пока не внедрён в игру. Настройки находятся в `stand_layouts.js`;
исходный синхронизированный каталог сохраняется отдельно.

При первом открытии обновлённого стенда меняется только инвентарь, прежний макет
сохраняется резервной копией в браузере. Остальные пользовательские окна сохраняются.

## Синхронизация с игрой

Каталог содержит все 32 определения `Gui/Default.foguischeme` и 9 дополнительных
состояний и оверлеев — всего 41 экран. Вместо прежних приближённых переработок
используются структура `.fogui`, текущие игровые изображения и атласы шрифтов.
HUD, инвентарь, меню E/Q, бонусы, навыки и описания предметов дополнены слоями,
которые рисуются игровыми скриптами. В каталоге 313 ресурсов изображений.

Игровой масштаб HUD по умолчанию 60%, инвентаря — 100%. Ограничения по размеру
экрана повторяют текущий клиент. «Масштаб игры» меняет размер самого интерфейса;
«Вписать» и кнопки приближения меняют только просмотр в редакторе.
Координаты и размеры свойств заданы в логических игровых пикселях.

Редактор не исполняет AngelScript и не подключается к серверу. Состав инвентаря,
числа, имена, тексты, откаты, состояние боя и изображение цели задания — примеры.
Динамические списки и анимации требуют проверки при переносе в клиент.

## Блоки и связанные экземпляры

- Клик выбирает блок целиком: предмет с изображением, патронами и износом,
  панель HUD или другое окно. Перемещение родителя переносит всех его детей.
- Ctrl + клик выбирает отдельную деталь. Alt + клик выбирает родителя.
  Shift + клик выделяет несколько блоков. В дереве «Слои» доступна любая деталь.
- Флажок «Связанные» по умолчанию включён. Изменение размера одной ячейки
  инвентаря меняет все ячейки этого шаблона вместе с их содержимым.
  Изображение предмета также может управлять размером всей своей ячейки.
  Картинки и тексты отдельных предметов при этом сохраняются.
- Связаны также размеры шрифтов, рамки, цвета и смещения одноимённых деталей.
  Перемещение целого экземпляра, его картинка и текст остаются независимыми.
- «При изменении размера» позволяет масштабировать всё содержимое или менять
  только панель. «Родитель растёт с содержимым» увеличивает панель при необходимости;
  автоматические ряд, колонка и сетка переставляют соседей с заданными зазорами.
  Рост не уменьшает панель автоматически; уменьшение доступно в её свойствах.
- Поле «Общий шаблон» связывает экземпляры в пределах одного экрана.
  «Роль внутри шаблона» связывает соответствующие детали. «Отвязать этот экземпляр»
  оставляет его независимым. Для разовой правки можно выключить «Связанные».
- Несколько деталей одного родителя можно объединить кнопкой «В группу».
  Ширина, высота и кнопка масштабирования группы работают со всем её содержимым.

## Оформление и управление

Доступны свободная компоновка, ряд, колонка, сетка, зазоры и внутренние отступы,
привязки к краям и центру родителя, обрезка, прозрачность, рамки, цвета и слои.
Рамка, нарисованная внутри игровой текстуры, является частью изображения;
для её замены измените ресурс или уберите картинку и настройте отдельную рамку.

Для текущего вида используется «Атлас HUD / инвентаря» или «Игровой пиксельный».
Чтобы выбрать системный шрифт, переключите «Отрисовку текста» на «Шрифт браузера».
Параметры насыщенности и курсива относятся к шрифтам браузера.
Новый шрифт при внедрении может потребовать подготовки игрового атласа.

Стрелки двигают на 1 px; Shift + стрелки — на 10 px. Ctrl+D создаёт копию;
Delete удаляет; Ctrl+Z / Ctrl+Shift+Z — отмена/повтор; Ctrl+S скачивает JSON.
Ctrl + колесо меняет масштаб просмотра. Alt при перетаскивании выключает
привязку к сетке; Shift при изменении размера сохраняет пропорции.

## Сохранение и передача

Правки автоматически сохраняются в браузере. Копии в разных браузерах, а также
при запуске через файл и localhost независимы. Для резервной копии используйте
«Скачать макет»: получится `newworld-interface-layout.json` со всеми экранами,
связями, настройками, исходными путями и списком изменений.
«Импорт» восстанавливает весь макет, включая связи блоков.

«Связать JSON» в Chrome/Edge позволяет автоматически записывать следующие правки
в выбранный файл. После переоткрытия страницы подключите файл снова.
Для последующего внедрения укажите агенту путь к сохранённому JSON.
Редактор самостоятельно не меняет `.fogui`, скрипты и запущенную игру.

Прежние приближённые макеты хранятся под отдельным ключом браузера и не стираются.
Импорт макета с другой основой отклоняется, чтобы не подменить текущие окна
устаревшими. Старый JSON можно сохранить отдельно как референс.

## Состав репозитория

Здесь размещены только самостоятельная страница редактора, каталог интерфейсов,
её изображения и проверка геометрии. Исходники основной игры, сервер, движок,
сохранения и снимок игровых GUI-скриптов в этот репозиторий не входят.
Каталог — снимок текущих интерфейсов, обновляемый отдельно от этого репозитория.
